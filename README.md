# Tabelas Estilizadas — HTML & CSS

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/docs/Web/CSS)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

Exercício do módulo **HTML e CSS Básico**: tabelas HTML estilizadas com CSS puro (sem framework).

Duas tabelas de exemplo — **Moda** e **Casa** — com cabeçalhos coloridos e linhas de dados em tema escuro.

**Demo online:** [denispaulo.github.io/aula-tabela](https://denispaulo.github.io/aula-tabela/)

## Demo

Abra o `index.html` no navegador.

```bash
# opcional
npx --yes serve .
```

## Conteúdo

| Tabela | Colunas              | Destaque do header |
|--------|----------------------|--------------------|
| Moda   | Produto, Tamanho, Valor | Roxo `#BB86FC`  |
| Casa   | Produto, Valor       | Verde-água `#00C4B4` |

## Como rodar

```bash
git clone https://github.com/DenisPaulo/aula-tabela.git
cd aula-tabela
# abra index.html no navegador
```

## Estrutura

```
aula-tabela/
├── index.html    # marcação das tabelas
└── styles.css    # cores, tipografia e layout
```

## Aprendizados

- Elementos de tabela: `table`, `tr`, `th`, `td`
- Estilização de cabeçalho e linhas com classes CSS
- Separação HTML / CSS
